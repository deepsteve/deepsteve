Deep Steve

Deep Steve runs coding agents in your browser. Each tab is one agent, working in one folder on this machine. Close the tab and it keeps going. Close the browser and it keeps going.

Out of the box it knows about exactly one folder — its own. That is this project, and on a new install it is the only row in the list on the left.

Start here

Point it at your own code

A project is a name and a folder. Any tab you open inside that folder groups under it, so one piece of work stays together.

  1. + New project, at the bottom of the list on the left. Name it.
  2. Add a folder — pick a recent one, or Browse… to go find it.
  3. Press + in the tab strip along the top. An agent opens in that folder and waits for you to say something.

That is the whole loop. Everything below here is optional.

This project is Deep Steve’s own code

Open a tab here and ask for a change the way you would in any other repo. This code is the sidebar, the shortcuts, the theme and the tab strip.

  • “The tab strip is too tall on a laptop screen. Fix it.”
  • “Write me a theme that looks like an amber terminal.”
  • “Add a keyboard shortcut that closes every tab in this project.”

Your change shows up after a restart

Ask the agent to restart Deep Steve when it is done. You get a confirm box first, and your open tabs reconnect afterwards.

Point it at a clone instead

Right-click the Deep Steve row → Edit to change the folder. If the path above is ~/.deepsteve, that is the copy Deep Steve is running and it has no history — an agent can change things there, but cannot commit them.

Don’t want it?

Hide it

Right-click the Deep Steve row → Hide Deep Steve. It comes back from Archived, at the bottom of the list, whenever you want it.

Close this tab when you are done with it. It does not open again.

⌘P hides and shows the project list. ⌘↑ and ⌘↓ move between projects once you have a few. ⌘? lists every keyboard shortcut there is.
