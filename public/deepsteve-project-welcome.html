The Deep Steve project

Every other project in the rail is code you are working on. This one is Deep Steve itself — the thing you are looking at right now. Open a tab here, describe a change, and the agent rewrites the app you are reading this in.

Open a tab in it, and ask

With Deep Steve selected in the rail, the + button in the tab strip — or ⌘K → New Tab — opens an agent session in the folder above. From there it is an ordinary conversation; the difference is what the code does when it runs.

  • “Add a keyboard shortcut that closes every tab in this project.”
  • “The tab strip is too tall on a laptop screen. Fix it.”
  • “Write me a theme that looks like an amber terminal.”

Changes land on a restart

The daemon serving this page is already running, so an edit on disk is not yet an edit in your browser. Deep Steve restarts itself through ./restart.sh, which asks you to confirm in the browser first and reconnects your open sessions afterwards — agents running under tmux are detached, not killed.

Ask the agent to restart when it is done, and it will offer you the dialog.

Pointing it somewhere else

The folder is a normal project setting, not a fixed path. Right-click the Deep Steve row → Edit to point it at a different checkout, or to add a second folder alongside the first.

A repo checkout is the better place to work if you have one: it has the full source, the tests and the version history, where ~/.deepsteve holds only the deployed copy the daemon is running from.

Or start a project of your own

“+ New project”, at the bottom of the rail

A project in Deep Steve is a name and a list of folders. It is not a scaffold and it creates nothing on disk — it groups the tabs you already have, so the rail shows one piece of work at a time.

  1. Press + New project and give it a name.
  2. Add one or more folders — pick from recent folders, or Browse… to walk the filesystem. The picker can create a new folder too, if the project doesn’t exist yet.
  3. Open a tab. Any tab whose working directory sits inside one of those folders joins the project automatically, worktrees included.

Moving between them

⌘P shows and hides the rail. ⌘↑ / ⌘↓ cycle projects. Selecting one filters the tab strip to it; All at the top shows everything again.

What a project gets you

A filtered tab strip, a folder that new tabs open in by default, a scope for scheduled tasks, and a home for project mods — dashboards an agent writes that live in the repo and travel with it.

Don’t want this project?

Hide it — it is not deletable, on purpose

Right-click the Deep Steve row, or the Projects header above the list, and choose Hide Deep Steve. It leaves the rail immediately.

Nothing is thrown away: it keeps its folder, its icon and its position, and it comes back from either the Archived section at the bottom of the rail or that same header menu, which then reads Show Deep Steve.
